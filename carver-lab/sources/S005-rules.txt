# carry 持有收益预测规则 修订版

修订日期：2026-10-25。依据本地提交 `164328bd76d2937d3dd61491377704c488283bc2`。

## 核心思想和输入口径

本模块提供绝对 Carry 与相对 Carry 两个规则。它们使用期限结构信息形成预测，不是已经实现的展期利润，也不构成无风险套利。

框架中的 `raw_carry` 是**年化期限价差除以年化价格变动波动率**，近似一个风险调整后的持有收益指标。它不是简单价差，也不是价差除以合约价格的百分比收益率。

上游处理链为：

```text
raw_roll = PRICE - CARRY
annualised_roll = raw_roll / 合约日期间隔（年单位）
daily_annualised_roll = 将年化价差按营业日取均值
raw_carry = daily_annualised_roll / (每日价格变动波动率 × 年化系数)
```

合约日期间隔由 Carry 合约日期减去 Price 合约日期构造，并有最小绝对间隔保护；不能默认所有数据的两条合约总是按同一近远月顺序存放。上游 `raw_roll` 恰为0时还会被置为缺失值。

商品反向市场可能对应正持有收益，但“供应紧张所以必然上涨”是经济解释，不是此函数的判断条件，不能直接推广到所有资产。

## 绝对 Carry 的公式

```python
forecast = raw_carry.ewm(smooth_days).mean()
```

默认 `smooth_days=90`。这里位置参数传给的是 **com**，不是 span：

```text
com=90 → alpha=1/91 → 等价span=181
```

它不是 `span=90`，也不是只看过去90天的固定窗口。pandas 默认使用 `adjust=True`。源码没有“正负必须持续若干天才能交易”的门槛。

`rawdata.smoothed_carry` 同样使用 `ewm(smooth_days)`。复现相对 Carry 时应保持两侧平滑口径一致。

## 相对 Carry 的公式

```text
relative_forecast = 本品种已平滑Carry - 所属资产类别已平滑Carry的横截面中位数
```

同类基准先分别平滑各品种的 `raw_carry`，再按日期取中位数；基准计算中不预先前向填充。最后再对齐到目标品种日期并前向填充。

正值表示本品种 Carry 高于同类中位数，负值表示低于中位数。这是相对预测，并不自动保证最终组合资金中性、风险中性或宏观敞口为零。

## 函数默认与示例配置

提供的 `rob_system/config.yaml` 配置了 `carry10/30/60/125`，分别显式传入 `smooth_days=10/30/60/125`；在上述实现中等价 span 为21/61/121/251。不能把默认90当成所有运行变体。

这些信号还需要系统级缩放、组合和仓位处理。能否预测后续收益、实际换手与成本，仍属于后续研究。
